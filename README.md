# Deploy on GitHub Pages
Create a public repository named YOUR-USERNAME.github.io under your GitHub account. Upload index.html and the assets directory at the repository root. In Settings > Pages choose Deploy from a branch, main, / (root), then Save. Open the published URL shown in Pages and test on mobile. Do not print the QR code until the final public URL is confirmed. Update index.html with verified audience metrics and individual video links when available. The supplied brand font is not bundled; check web embedding rights before adding it. No build or dependencies required.
